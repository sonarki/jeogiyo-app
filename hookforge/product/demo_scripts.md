# HookForge 데모 광고 스크립트 — 뷰티 니치 (가상 브랜드)

> 데모용 가상 브랜드: **GLOWRA** — 비타민C 글로우 세럼 (실존 브랜드 아님, 상표 충돌 회피용 조어)
> 목적: "이런 걸 20편 드립니다"의 증거물. 포트폴리오 = 영업 자산.
> 규격: 9:16 세로 · 8~15초 · 훅은 첫 3초 · AI 보이스오버 + 자막 번인
> ⚠️ 의학적 효능 주장 금지 (미백/치료/개선 보장 X). "glow", "feels", "looks" 수준의 소프트 클레임만.

## 생산 원칙 (일관성 시스템)

1. **제품 히어로 이미지 1장을 먼저 생성** (GLOWRA 병 디자인 확정) → 이후 모든 영상에 reference media로 재사용 → 제품 외형 일관성 확보
2. UGC 모델(인물)은 영상마다 달라도 됨 (실제 UGC도 크리에이터가 여러 명) — 오히려 다양성이 자연스러움
3. 영상 생성은 Higgsfield 워크플로 카탈로그(UGC/ad) 확인 후 그 절차를 따름
4. 모든 데모에 "AI-generated demo ad" 워터마크 각오하고 투명하게 — 이게 셀링포인트

## 데모 9편 스크립트

### D1 — Talking-head 후기형 / 훅: 문제 제기
- **Hook (0-3s)**: 얼굴 클로즈업, 살짝 지친 표정 → "My skin looked so tired lately…"
- **Body (3-10s)**: 세럼 병 들어올림, 미소 → "Then I tried this vitamin-C serum. Two drops, morning and night."
- **CTA (10-13s)**: 볼 터치하며 → "My glow is BACK. Link below."
- 자막 스타일: 큰 흰색 볼드 + 키워드 옐로 하이라이트

### D2 — Talking-head 결과 선공개형 / 훅: POV
- **Hook**: 밝은 조명, 광나는 피부 클로즈업 → "POV: you finally found the serum that actually works with your skin."
- **Body**: 제품 보여주며 텍스처 한 방울 손등 시연
- **CTA**: "GLOWRA. That's it. That's the routine."

### D3 — Talking-head 회의론자형 / 훅: 반전
- **Hook**: 팔짱, 의심스러운 표정 → "I did NOT want to like this serum."
- **Body**: 어깨 으쓱, 제품 응시 → "But it's been two weeks and… look at this glow."
- **CTA**: "Fine. You win, GLOWRA."

### D4 — ASMR 제품 클로즈업 / 훅: 감각
- **Hook**: 스포이드에서 세럼 방울 떨어지는 매크로 샷 (물방울 소리)
- **Body**: 병 회전, 텍스처가 유리판에 퍼지는 샷, 손끝으로 문지르는 샷
- **CTA 자막만**: "Glow in a bottle. GLOWRA."
- 오디오: 앰비언트 ASMR (보이스오버 없음)

### D5 — 언박싱형 / 훅: 기대감
- **Hook**: 오렌지색 패키지 박스 손으로 잡는 오버헤드 샷 → 자막 "The serum everyone's talking about"
- **Body**: 박스 개봉, 티슈 페이퍼, 병 꺼내 조명에 비춤
- **CTA**: "Worth the hype? Absolutely."

### D6 — 루틴 브이로그형 / 훅: 시간대
- **Hook**: 아침 세면대 셀피 앵글 → "6AM skincare, 30 seconds, let's go."
- **Body**: 세안 → 세럼 2방울 → 두드리며 흡수 (빠른 컷 3개)
- **CTA**: "Glow done. Coffee time. ✨"

### D7 — 스트리트 인터뷰형 / 훅: 질문
- **Hook**: 거리에서 마이크 든 인터뷰어 → "What's your skincare secret?"
- **Body**: 행인 웃으며 가방에서 GLOWRA 꺼냄 → "Everyone asks me that!"
- **CTA**: "It's this. Every time."

### D8 — 비포/애프터 소프트형 / 훅: 대비 (⚠️ 소프트 클레임)
- **Hook**: 분할 화면 — 왼쪽 노 메이크업 무광 조명 / 오른쪽 글로우 조명 → "Same skin. Two weeks apart."
- **Body**: 오른쪽 화면 확대, 자연광 글로우
- **CTA**: "The only thing I changed? GLOWRA."
- 주의: "치료됨/미백됨" 금지. 조명·컨디션 차이 수준의 연출로.

### D9 — 밈/트렌드형 / 훅: 유머
- **Hook**: "Me pretending I was born with this glow:" + 새침한 표정
- **Body**: 카메라 밖에서 세럼 병이 프레임 안으로 슥 들어옴, 모델 킥킥
- **CTA**: "GLOWRA knows the truth. 🤫"

## 생산 순서 (승인 후 실행)

1. GLOWRA 제품 히어로 이미지 1장 생성 (병 디자인 확정) — 이미지, 저비용
2. Higgsfield 워크플로 카탈로그 로드 → UGC/광고 워크플로 지침 확인
3. 견적 산출 (편당 크레딧) → **캡틴 승인** → 배치 생성 (D1, D4, D7 우선 — 포맷 다양성 최대 3종)
4. 결과 검수 → 통과작 틱톡 게시 승인 요청 → 랜딩 데모 섹션 임베드

## 판매용 재사용

이 9개 골격이 곧 **납품 템플릿**이다. 고객 제품이 들어오면:
훅 5종(문제/POV/회의론/감각/유머) × 포맷 4종(토킹헤드/ASMR/언박싱/스트리트) × 변형 = 20편 매트릭스가 기계적으로 나온다.
