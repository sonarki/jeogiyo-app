# 캡틴 셋업 체크리스트 — 총 25~30분, 이게 네 숙제의 전부

> 원칙: **전부 신규 계정.** 캡틴의 기존 채널·계정·IP는 일절 사용하지 않는다.
> 완료 보고는 한 줄이면 됨: `이메일 됐어 / X @핸들 / 틱톡 @핸들 / 검로드 됐어`

---

## STEP 0 — 브랜드 Gmail (5분) ★모든 가입의 베이스

1. gmail.com → 계정 만들기
2. 추천 주소 (위에서부터 시도):
   - `hookforge.studio@gmail.com`
   - `hookforge.hq@gmail.com`
   - `gethookforge@gmail.com`
3. 복구 전화번호는 본인 번호 OK (외부 노출 안 됨)

## STEP 1 — X / 트위터 (5분)

1. x.com → 신규 가입 (STEP 0 Gmail 사용)
2. 핸들 (위에서부터 시도): `@hookforge` → `@hookforgestudio` → `@gethookforge`
3. 표시 이름: `HookForge — AI Ad Studio`
4. bio/헤더/프로필 이미지는 내가 만들어서 전달 → 복붙/업로드만
5. ⚠️ 가입 직후 아무한테도 DM 보내지 말 것 (신규 계정 스팸 필터 민감. 워밍업 순서는 내가 지시)

## STEP 2 — TikTok (5분)

1. tiktok.com → 신규 가입 (STEP 0 Gmail 사용)
2. 핸들 동일 규칙: `@hookforge` 계열
3. **완료되면 나한테 "틱톡 됐어"라고만 말해줘**
   → 내가 Higgsfield 연결 링크(tiktok_connect)를 쏴줌
   → 캡틴은 그 링크에서 승인 버튼 1번
   → 이후 **영상 게시는 내가 직접 실행** (캡틴 손 안 감)

## STEP 3 — Gumroad (5분)

1. gumroad.com → Start selling → 가입 (STEP 0 Gmail 사용)
2. 스토어 이름: `HookForge`
3. 상품 등록은 아직 하지 마 — 내가 제목/설명/가격/커버 이미지 전부 만들어서 "복붙 순서표"로 넘김
4. **정산 계좌(payout) 설정은 나중에 해도 됨.** 판매(결제 수취)가 먼저고, 정산은 첫 매출 이후 설정해도 늦지 않음
5. 수수료 참고: 10% + $0.50/건 — 비싸지만 즉시 개설 + 전세계 카드 + 세금 자동처리(MoR)라 72h 작전엔 최적

## STEP 4 — (선택, 여유 있을 때) PayPal

- 에이전시 인보이스 클로징용. 없어도 시작 가능. $1,000+ 건 잡히면 그때 열어도 됨
